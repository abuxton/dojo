# Mission: Apple Intelligence Local Inspection

## Why
Safely inspect the local Intelligence Platform data on this Mac and understand
how an app can use Apple Foundation Models without assuming access to that data.
This supports informed privacy decisions and safer Apple Intelligence prototypes.

## Success looks like
- Inspect local store metadata with a read-only command and keep personal records local.
- Explain the boundary between the Intelligence Platform and the Foundation Models framework.
- Build an app flow that checks AFM availability and provides a fallback.

## Constraints
- Use local, read-only tooling for personal data.
- Ground API claims in current Apple documentation and label reverse-engineered claims.
- Keep each lesson short and practical.

## Out of scope
- Extracting, publishing, or sharing personal graph records.
- Treating reverse-engineered implementation details as a stable Apple API.
