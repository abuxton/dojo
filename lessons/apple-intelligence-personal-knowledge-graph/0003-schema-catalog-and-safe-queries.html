Choose an execution mode

./bin/intelligence-platform --dry-run schema entity
./bin/intelligence-platform --do-nothing
./bin/intelligence-platform schema entity

--dry-run prints the operation without opening the store. --do-nothing prints and pauses through a manual procedure without executing commands. With neither mode, the utility runs read-only SQLite operations. preview is the only helper below that displays records, and it runs only when you explicitly choose it.
