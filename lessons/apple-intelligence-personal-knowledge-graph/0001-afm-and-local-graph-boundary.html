Lesson 1 · 10 minutes · safe local inspection

AFM is not your Mac’s personal graph

Your goal is to inspect the local Intelligence Platform safely and design an app that does not assume it can query it.

One distinction to retain: AFM is the documented model layer. The Intelligence Platform is the local OS data store described by third-party research. Finding the latter does not prove a public bridge to the former.

Learn the boundary

Apple documents SystemLanguageModel and LanguageModelSession in its Foundation Models framework. The 8rank article reports a local store under ~/Library/IntelligencePlatform, but that report is reverse-engineering from a specific macOS release, not an API contract.

For an app, use an explicit tool or a trusted data source when the model needs data. Check model availability first and provide a fallback if it is unavailable.

Do one safe thing

Run this command. It lists only local platform files; it does not copy or modify them.

cd /Users/abuxton/src/github/dojo/lessons/apple-intelligence-personal-knowledge-graph
./bin/intelligence-platform inventory

If the directory is absent, that is a valid result. If macOS denies access, decide deliberately whether to give your terminal Full Disk Access—the utility tells you when macOS has denied this access—then revoke it later if you do not otherwise need it. Never paste personal query output into chat, issues, or source control.
