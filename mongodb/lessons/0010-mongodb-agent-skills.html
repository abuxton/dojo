Give an agent the right playbook

A MongoDB agent skill is focused instruction for an agent, not a connection to your database. Choose the skill that matches the task before asking the agent to act.

TaskAsk a plain-language question about lesson data.
SkillUse mongodb-natural-language-querying.
ToolUse MCP only when the agent needs database context.

The official MongoDB agent-skills repository includes focused skills for connection setup, natural-language querying, schema design, query optimization, Search and AI, Atlas Stream Processing, and Queryable Encryption sizing. A skill narrows the agent's workflow; it does not itself configure an MCP server.

Choose the skill for the job

mongodb-mcp-setup: configure or troubleshoot an MCP server, its connection string, or required environment variables. Do not select it for an ordinary query when mcp.json already works.

mongodb-connection: change MongoClient settings, connection pools, or timeouts, or diagnose a connection failure.

mongodb-natural-language-querying: turn a learner's question into a read-only find query or aggregation. Inspect schema and sample documents through MCP first.

mongodb-query-optimizer: investigate a slow query, an explain plan, or an index choice. It is not needed for a first-pass query tutorial.

mongodb-schema-design: evaluate a data model, embedding versus references, JSON Schema validation, or data lifecycle decisions.

mongodb-search-and-ai: work with Atlas Search, Vector Search, embeddings, RAG, or relevance. It needs an Atlas-capable deployment, not this local container alone.

mongodb-atlas-stream-processing: build or operate an Atlas Stream Processing workflow. Use it only for an explicit stream-processing exercise.

mongodb-qe-size-estimation: estimate the storage impact of Queryable Encryption. Use it only for an explicit Queryable Encryption sizing exercise.

Primary source: MongoDB Agent Skills. See the research note for installation paths and the full skill list.
