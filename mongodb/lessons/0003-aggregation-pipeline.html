Turn order items into sales totals

An aggregation pipeline passes documents through ordered stages. Lab 03 turns nested order items into one sales row per product.

$unwind items → $group by product → $project fields → $sort revenue

$unwind makes one pipeline document per array item. $group combines those documents by a key. Later stages receive the output from earlier ones.

Source: MongoDB Manual: Aggregation.

Predict the top product by revenue, then run:

npm run lesson:03
