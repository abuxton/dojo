Make a connection explain itself

The local client reads its URI, database, app name, and timeout from configuration, then pings MongoDB before it does application work.

new MongoClient(uri, {
  appName,
  serverSelectionTimeoutMS,
})

appName identifies the client in server metadata. serverSelectionTimeoutMS bounds how long the driver waits to choose a server. This lab uses a short local-development timeout, not a universal production recommendation.

Source: Node.js Driver: Connection Options.

Run the configuration check:

npm run lab:04:client

Then set MONGODB_APP_NAME in your shell, rerun it, and confirm the printed value changed.
