Ask for only the books you need

Lab 02 turns a collection into a useful application query: filter the candidates, project the useful fields, then sort them.

books.find(
  { category: "database", price: { $lte: 30 }, inStock: true },
  { projection: { _id: 0, title: 1, price: 1 } },
).sort({ price: 1 })

A filter chooses matching documents. A projection limits returned fields. A sort orders the matches. The compound index on category and price is a structure the server can use to find a subset efficiently.
