Make the database visible

Compass is the local desktop client for inspecting the same collections that the drivers and shell use. It does not create a second database or copy your lesson data.

mongodb://127.0.0.1:27017/mongodb_learning

The launcher passes this host connection string to Compass. Save it as MongoDB Learning Lab, then browse documents, indexes, and aggregation stages.

Source: MongoDB Compass Documentation.
