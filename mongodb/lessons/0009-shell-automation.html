Make a query useful to another program

Lab 09 runs a fixed, read-only mongosh query from a POSIX shell script and prints one JSON array. That makes its result easy to save or pass to another tool.

./scripts/09-shell-automation.sh > students.json

Use the script directly when redirecting output. npm run adds its own command banner, which is useful for humans but not part of the JSON result.

A local mongod speaks the MongoDB wire protocol, not HTTP; that is why this lab uses mongosh, not curl.

Source: MongoDB Shell Documentation.

npm run lesson:01
npm run lab:09:shell

Then run the script directly with output redirection and inspect the JSON array.
