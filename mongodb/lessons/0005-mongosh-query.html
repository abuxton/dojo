Query without changing app code

Lab 05 runs mongosh from the Docker tools service, then asks the same question as a driver query: which students completed two or more lessons?

db.lesson_01_students.find(
  { completedLessons: { $gte: 2 } },
  { _id: 0, name: 1, track: 1, completedLessons: 1 },
).sort({ name: 1 })

mongosh is useful for inspecting a database interactively or running a small script. It uses the same query language as the driver, but it is not your application's runtime.

Source: MongoDB Shell Documentation.

npm run lesson:01
npm run lab:05:mongosh
