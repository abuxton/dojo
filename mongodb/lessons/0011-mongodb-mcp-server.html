Lesson 0011 · 8 minutes

Let an AI client inspect, not change

The MongoDB MCP Server lets an AI client use MongoDB context and tools. This course connects it only to the local mongodb_learning database and keeps the server read-only.

{
  "args": ["-y", "mongodb-mcp-server@latest", "--readOnly"],
  "env": {
    "MDB_MCP_CONNECTION_STRING":
      "mongodb://127.0.0.1:27017/mongodb_learning"
  }
}

mcp.json contains this configuration. --readOnly is the important boundary: the agent can inspect the seeded lesson data but cannot modify it through this server.

The official MCP Server supports local self-hosted and Atlas Managed deployments. This lesson uses the local option because the course already runs a local MongoDB container; it is not an Atlas administration setup.

Primary source: MongoDB MCP Server Overview. Configuration details: Local MCP options.

npm run db:up
copilot --additional-mcp-config @mcp.json

Run Lesson 01 first if you need sample data. Then ask the AI client to list the available collections or describe a lesson collection. Verify that the request is inspect-only; do not remove --readOnly.
