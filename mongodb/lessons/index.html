Guided course

MongoDB Learning Lab

Nine short lessons tied to the scripts in this repository. Each card previews the operation you will run.

Lesson 01

Documents and CRUD

Create, read, update, then delete student documents.

insertMany([...])
updateOne(...)
deleteOne(...)
Lesson 02

Query and index

Return affordable books with only the fields you need.

find(filter, projection)
.sort({ price: 1 })
Lesson 03

Aggregation

Turn nested order items into product sales totals.

$unwind → $group
→ $project → $sort
Lab 04

Client connection

Identify the local client and check its connection.

new MongoClient(uri,
  { appName, timeout })
Lab 05

mongosh

Run the student query outside application code.

db.students.find(
  { completedLessons: { $gte: 2 } })
Lab 06

Export and backup

Produce readable JSON and a restorable BSON dump.

mongoexport
mongodump
Lab 07

Compass

Browse collections, indexes, and the aggregation visually.

mongodb://127.0.0.1
:27017/mongodb_learning
Lab 08

PyMongo

Repeat the driver operations from Python.

students.update_one(
  filter, update)
Lab 09

Shell automation

Emit a read-only query result as JSON.

mongosh --quiet --eval
JSON.stringify(...)
Run project commands with npm run …, not npx run ….
