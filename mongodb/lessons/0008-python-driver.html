Keep the database concept, change the language

The Python lab repeats CRUD, querying, aggregation, and client configuration with PyMongo. The methods look different, but the documents and query language are the same.

students.update_one(
  {"name": "Ada"},
  {"$inc": {"completedLessons": 1}},
)

PyMongo uses synchronous method calls such as find_one and update_one. It writes to its own lesson_08_python_* collections, preserving the Node.js data.

Source: PyMongo Documentation.
