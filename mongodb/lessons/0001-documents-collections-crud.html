From app data to a MongoDB document

Your local app needs somewhere to keep a student's name, learning track, and completed lessons. In MongoDB, that one student is a document.

Databasemongodb_learning
Collectionlesson_01_students
Document{ name: "Ada", ... }

A document is a set of field-and-value pairs. A collection holds documents of a similar application concern; a database groups collections. MongoDB's official manual describes documents as JSON-like values that can also contain nested documents and arrays.

Source: MongoDB Manual: Introduction.

Read the existing lab as an app story

await students.insertMany([
  { name: "Ada", track: "database-basics", completedLessons: 1 },
  { name: "Grace", track: "database-basics", completedLessons: 2 }
]);

students is the collection. Each object is a document. MongoDB creates a unique _id when the driver inserts a document without one.

Source: MongoDB Node.js Driver: Insert Documents.
