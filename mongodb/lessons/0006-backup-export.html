Choose JSON for reading, BSON for restoring

Lab 06 produces two artifacts from one collection. They are related, but they serve different jobs.

mongoexportreadable JSON
mongodumpBSON backup
mongorestorerestore BSON

Use JSON to inspect or exchange simple documents. Use the BSON dump when you want a database-oriented backup and restore workflow. The lab writes both outputs to ignored local artifacts.

Source: MongoDB Database Tools.

npm run lesson:01
npm run lab:06:export

Open the JSON file under .mongodb-learning-artifacts/lab-06/. Do not restore over mongodb_learning; the lab documents a separate restore name.
