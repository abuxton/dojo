Quick reference

Skills guide; MCP connects

Use a MongoDB agent skill to choose a reliable workflow. Use the MongoDB MCP Server only when that workflow needs database context or tools.

Agent skillTask-specific instructions for an agent.
MCP ServerA bridge from an AI client to MongoDB tools.
Course defaultLocal database with read-only MCP access.

Choose the skill

mongodb-mcp-setup — configure or troubleshoot MCP.

mongodb-natural-language-querying — turn a question into a read-only query.

mongodb-schema-design — make a data-model decision.

mongodb-query-optimizer — investigate a slow query or index.

Use the safe local workflow

npm run db:up
copilot --additional-mcp-config @mcp.json

Keep --readOnly and the mongodb_learning connection string. Ask for inspection or a proposed read-only query; verify the generated operation before use.
