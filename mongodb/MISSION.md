# Mission: Local MongoDB application development

## Why
Build confidence using MongoDB in local application projects, so database
features can be developed, inspected, and changed without relying on a hosted
service or guessing how the driver behaves.

## Success looks like
- Start the local deployment, connect an application, and explain where its data lives.
- Add and query a small application feature using a document, collection, and index.
- Choose the right local tool—driver, shell, Compass, MCP, or Database Tools—for a task.

## Constraints
- Learn through short, hands-on labs in this repository.
- Use the existing local Docker deployment and fictional data.
- Start with application development, not operations or production scaling.

## Out of scope
- Atlas administration, production capacity planning, and distributed-cluster operations.
- Search, vector search, and stream processing until core CRUD and data modeling are comfortable.
