# MongoDB Local Application Development Resources

## Knowledge

- [MongoDB Manual: Introduction](https://www.mongodb.com/docs/manual/introduction/)
  Primary explanation of the document model, documents, collections, and databases. Use for the
  core data model.
- [MongoDB Node.js Driver: Insert Documents](https://www.mongodb.com/docs/drivers/node/current/crud/insert/)
  Official reference for `insertOne()` and `insertMany()`. Use when reading or extending the
  Node.js CRUD lab.
- [MongoDB Node.js Driver: Retrieve Data](https://www.mongodb.com/docs/drivers/node/current/crud/query/retrieve/)
  Official reference for filters, projections, sort order, and cursors. Use for Lab 02.
- [MongoDB Manual: Aggregation](https://www.mongodb.com/docs/manual/aggregation/)
  Primary explanation of aggregation pipelines and stages. Use for Lab 03.
- [MongoDB Node.js Driver: Connection Options](https://www.mongodb.com/docs/drivers/node/current/connect/connection-options/)
  Reference for `MongoClient` options such as `appName` and timeouts. Use for Lab 04.
- [PyMongo Documentation](https://pymongo.readthedocs.io/en/stable/)
  Official Python driver reference. Use when comparing the Python lab with the Node.js version.
- [MongoDB Shell Documentation](https://www.mongodb.com/docs/mongodb-shell/)
  Official reference for interactive queries and shell automation. Use for Labs 05 and 09.
- [MongoDB Database Tools](https://www.mongodb.com/docs/database-tools/)
  Official documentation for BSON backup and restore plus JSON import and export. Use for Lab 06.
- [MongoDB Compass](https://www.mongodb.com/docs/compass/)
  Official desktop GUI documentation. Use for visual inspection in Lab 07.
- [MongoDB MCP Server](https://www.mongodb.com/docs/mcp-server/)
  Official MCP server documentation. Use when safely exploring the local database through an AI client.
- [MongoDB MCP Server Overview](https://www.mongodb.com/docs/mcp-server/overview/)
  Primary explanation of the local and Atlas Managed MCP Server options. Use for Lesson 11's
  read-only local workflow and deployment boundaries.
- [MongoDB Agent Skills](https://github.com/mongodb/agent-skills)
  Official collection of MongoDB agent skills for agentic workflows. Use for Lesson 10 when
  selecting a task-specific skill before an agent queries or manages MongoDB.

## Wisdom

- [MongoDB Developer Community Forums](https://www.mongodb.com/community/forums/)
  Moderated community with MongoDB engineers and experienced users. Use for a real query,
  data-model, or driver problem after reducing it to a reproducible example.
